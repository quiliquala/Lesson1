My Journey into Web Development

Last year I decided to learn web development from scratch. I had never written a line of code before, so everything felt new and a little scary. My goal was simple: build a small website that I could proudly show to my friends.

I started with HTML, because it is the foundation of every web page. My first page said Hello, World! and I was very happy. Then I learned about semantic HTML, and I realized that meaning matters as much as appearance.

Choosing the right element makes a page easier to read and easier to find. Most importantly, it makes a website accessible to everyone. This is why I try to use the correct tag every time.

Every day I practice a little, make mistakes, and fix them. I now enjoy debugging more than I expected. Learning to code is not easy, but it is exciting, and I am proud of my progress so far.
